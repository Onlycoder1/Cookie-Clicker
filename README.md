# Cookie Clicker
This is the simple cookie clicker that I made. Keep in mind this is my first Pygame project and could be improved further.

## Game Description
The game starts off with 0 cookies and you have to try and achieve 100,000 cookies once that is achieved you win the game. 

## Tools Used:
I used pygame for this game and pybag for the web game.
## Problems Faced: 
Pygame was new to me so a lot of this project had a steep learning curve.
